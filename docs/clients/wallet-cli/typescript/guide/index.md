# 指南

测试网上运行。

| 指南 | 涵盖内容 |

| [快速上手](getting-started.md) | 创建钱包、在 Nile 上充值、查看余额、发送第一笔交易 |
| [发送 token](send-tokens.md) | 发送原生 TRX 和 TRC20 / TRC10 token；token 地址簿 |
| [质押与资源](stake-and-resources.md) | 质押、代理和解质押 TRX 以获得能量 / 带宽 |
| [使用 Ledger](ledger.md) | 注册 Ledger 硬件钱包并用它签名 |
| [脚本编写](scripting.md) | 安全地从 shell 脚本和 CI 调用 wallet-cli |

逐条命令的细节请见[命令参考](../commands/index.md)；JSON 接口规范请见
[machine-interface](../machine-interface.md)。
